# Betleem față de ProPresenter (Pasul 18)

Sursa: lista oficială de funcții ProPresenter (renewedvision.com/propresenter/all-features), noiembrie 2026.

✅ = avem · 🟡 = avem parțial · ⏳ = urmează (în ordinea importanței pentru o biserică)

| ProPresenter | Betleem | Unde / ce lipsește |
|---|---|---|
| Playlists, arrangements, căutare rapidă | ✅ | program, structura cântării pe etichete, căutare în bibliotecă |
| Planning Center (sincronizare) | ✅ | import din PCO, două conturi; plus planificare proprie |
| Stage display: acum / următorul, mesaje doar pe scenă | ✅ | ecranul de scenă, mesaj cu ținta „scenă” |
| Timere și ceasuri, numărătoare | ✅ | timerul slujbei (galben/portocaliu/roșu), numărătoare cu fundal |
| Previzualizare live a ecranelor | ✅ | 🖥 Sală / Scenă |
| Tranziții | ✅ | textul se estompează; tranzițiile din PowerPoint (fade, push, wipe…) |
| Biblie | ✅ | două traduceri pe ecran, pasaj în program |
| MIDI | 🟡 | lumini prin MIDI (scene, trecere lină, legate de secțiuni); încă nu primim comenzi MIDI ca să schimbăm slide-uri |
| Network Link (mai multe calculatoare) | ✅ | „Mai multe calculatoare”: versuri pe unul, track-uri pe altul |
| Control de pe telefon (Remote) | ✅ | pagina de telefon, modul Predicator |
| Track-uri (MultiTracks) | ✅ | MD&TRACK: mixer, rutare, tempo, ton, secțiuni, track virtual |
| Macros (mai multe acțiuni dintr-un buton) | ⏳ 1 | ex. „Începe slujba” = fundal + timer + lumina Închinare + primul slide |
| Slide actions (acțiune la un slide) | 🟡 | lumina se schimbă singură la secțiune; ⏳ alte acțiuni (video, timer) pe slide |
| Looks (ce strat pe ce ecran) | 🟡 | „ce apare pe scenă” e reglabil; ⏳ mai multe „looks” salvate și 3+ ecrane |
| Straturi care se șterg separat | 🟡 | Ecran gol (tot), ascunde textul, logo; ⏳ butoane separate: text / fundal / media / mesaj |
| Props (logo, banner peste orice) | 🟡 | logo; ⏳ props proprii (de ex. „Bine ați venit”, numele vorbitorului) |
| Announcements (a doua prezentare pentru hol / stream) | ⏳ 2 | ecran separat pentru hol, cu anunțuri în buclă |
| Video input (cameră) | ⏳ 3 | camera ca fundal sau pe ecran, cu versurile peste |
| NDI / SDI / Alpha key (pentru stream) | ⏳ 4 | ieșire pentru OBS: avem /overlay în plan (versuri cu fundal transparent) |
| Masks, edge blend | ⏳ (rar la noi) | — |
| Timecode, Stream Deck | ⏳ (rar la noi) | Stream Deck se poate face prin scurtături de tastatură |

**Ordinea propusă după prezentare:** macro-uri (1), ecran pentru hol (2), cameră (3), ieșirea pentru stream/OBS (4),
apoi straturi separate și props. Fiecare se face „pe ce există” (regula de aur): macro-urile refolosesc acțiunile deja
existente (fundal, timer, lumini, slide), iar ecranul de hol refolosește ecranul principal cu un alt program.
