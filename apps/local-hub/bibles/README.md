# Biblii incluse (domeniu public)

- `vdc.json` — Cornilescu, Romanian Corrected Cornilescu Version (domeniu public), din seven1m/open-bibles (`ron-rccv.usfx.xml`)
- `kjv.json` — King James Version (domeniu public), din seven1m/open-bibles (`eng-kjv.osis.xml`)
- `web.json` — World English Bible (domeniu public), din seven1m/open-bibles (`eng-web.usfx.xml`)

Alte traduceri (EDCR, NTR, NIV…) sunt protejate de drepturi de autor: fiecare biserică le importă din Betleem
(Live → Biblia → ⇪) dintr-un fișier pe care are dreptul să-l folosească (Zefania XML, OSIS, USFX sau JSON).
Se salvează în `Documente/Betleem/bibles/`.
